# Bedrock Seed Explorer

Minecraft統合版向けAndroidアプリの開発プロジェクトです。Java版のデータ・切替機能は対象外です。

## 現在の状態
- Androidアプリの基本画面とGitHub ActionsによるDebug APKビルド設定を準備中
- Seed値・座標入力のUIを実装
- バイオーム／構造物データ取得は未接続。地形・構造物の正確な表示はまだできません

## ビルド
GitHubのActionsから「Android APK build」を実行し、成功したRunのArtifactsからAPKを取得します。

非公式の補助アプリです。Minecraft公式とは関係ありません。
